# Notes

Use this folder for paper-line reading notes, decision logs, and experiment logs.

Keep one note per source or decision. A simple note should include:

- date
- source or question
- takeaway
- relevance to the paper-line
- what is out of scope
- next action

Keep notes short and citation-heavy. If a fact depends on MATLAB, ROS, or a paper version, record the exact version or link.
